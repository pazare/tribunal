## 1. Build inventory

### 1.1 What the project is

**Tribunal** — "an explainable decoder: high-stakes verdicts are generated span by span, and every span is elected" (README.md:3). Replaces one-shot generation with a recorded election per surface unit using mechanisms adapted from human institutions: secret ballots (sealed commitments), aggregate identity-hidden critique with ballot-order rotation, on-record vote changes, safety veto, ratification under a named rule, minority reports; everything lands in a hash-chained tamper-evident verdict ledger (README.md:9). Authorship: Pablo Zavala, CMU (README.md:5). Built at RAISE Summit Hackathon 2026, Cursor track; MIT (README.md:17). Three sibling systems, "not one undifferentiated architecture" (SANTIAGO §1.9, lines 223-236): six-seat general engine → elected text spans; **Decoder Lab** (two pinned CLI principals, exact `span|space|enter|stop` units, 2/2 quorum); **Clinical Eval** (four clinical-role seats, coded escalation tuples, five-arm revisions, safety packet).

- `HANDOFF.md` (repo root, **not tracked** — `git ls-files HANDOFF.md` returns nothing; gitignored per HANDOFF.md:4) is a stale July-5 hackathon operator brief; still authoritative for the standing rule "Never put a Fable model on a Tribunal seat" (HANDOFF.md:31-33, echoed CONTINUITY_PLAN §1).
- `CONTRIBUTING.md:41-59` — eight non-negotiable honesty invariants (claim auditability not answer quality; offline never model output; baseline asymmetry honest; anonymization is field-level not stylometric; repairs fail the scorecard; worker verify kept in sync).
- `package.json` — npm workspaces monorepo (`packages/*`, `apps/*`), scripts: `demo`, `demo:real`, `dev`, `record:demo`, `submit:prep`, `experiment:clinical:{simulate,analyze,verify}` (package.json:14-29).
